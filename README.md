# Sweet Pink Corner - Backend
Projektuppgift - DT207G

Detta repository innehåller frontend-delen av webbapplikationen Sweet Pink Corner. Applikationen är utvecklad med HTML, CSS och JavaScript och kommunicerar med ett REST-API för att hämta och hantera produkter.

## Av: Frida Ljungberg, 2026

### Funktioner
- Visa produkter från databasen
- Administratörsinloggning
- Lägga till produkter
- Redigera produkter
- Ta bort produkter

OBS! Backend-API:et måste vara igång för att produkterna ska kunna hämtas och visas på webbplatsen!
